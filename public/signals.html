What each status means

Watching

No complete setup yet. ForexBot continues scanning new closed candles.

Filtered / shadow tracked

A trade idea exists but failed one or more gates. It is followed internally so we can learn whether rejecting it helped.

Waiting for entry

The setup qualified. If it was sent to XM, XM monitors live price; otherwise ForexBot monitors the planned entry internally.

Entry triggered

Price reached the entry. Stop, target and holding-time rules now control the outcome.

Expired

The entry price was never reached before the allowed entry window closed.

Finished

The target, stop or time-limit outcome has been recorded for performance monitoring.

The console is designed to reduce unnecessary intervention. A quiet bot is not automatically a broken bot: no order is preferable to a setup that has not demonstrated enough edge. Automatic execution remains demo-only.
